엠파시(Empasy)의 SyncSeries AI 자율 운영 생태계(Agent-to-Agent) 공식 기술 문서 및 개발자 가이드 포털 저장소입니다.

  • 공식 기업 홈페이지: https://empasy.io
  • GitHub Organization: https://github.com/DramaticCollaboration/

2. 로컬 개발 및 빌드 가이드 ​

사전 요구사항 ​

  • Node.js: v20+ 권장
  • 패키지 매니저: pnpm (또는 npm)

의존성 설치 ​

bash
pnpm install

로컬 개발 서버 실행 (http://localhost:5173) ​

bash
pnpm run docs:dev

프로덕션 정적 사이트 빌드 및 링크 무결성 검증 ​

bash
pnpm run docs:build

빌드 결과물 로컬 프리뷰 ​

bash
pnpm run docs:preview
