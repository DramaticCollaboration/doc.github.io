상황별 실전 프롬프트 모음집 (치트시트) ​

활용 안내: 본 프롬프트 모음집은 기획, 설계, 구현, 테스트, 오류 해결, 배포에 이르는 개발 전 단계에서 부분만 프로젝트 상황에 맞게 바꾸어 복사·붙여넣기로 활용할 수 있도록 정리한 실무 템플릿입니다.

목차 및 빠른 이동 ​

  • 1. 기획 및 요구사항 분석 (기획자 / PO)
  • 2. 아키텍처 및 데이터베이스 설계 (아키텍트 / DBA)
  • 3. 백엔드 Java Spring Boot 구현 (백엔드 개발자)
  • 4. 프론트엔드 Vue 3 및 모달 분리 (프론트엔드 개발자)
  • 5. 테스트 및 품질 검증 (QA 엔지니어)
  • 6. 오류 해결 및 자동 수정 (디버깅 / 트러블슈팅)
  • 7. 코드 검토 및 배포 요약 (리뷰어 / 운영자)
