On this page

Engineering Research Archive (Study) ​

This archive documents in-depth research on implementation principles, performance benchmarks, and architecture design patterns for the core technology stack powering Empasy SyncSeries products (SyncETA, SyncVerse, SyncBoot, SyncCrawl, and more).

Core Research Categories ​

1. Web Browser Automation & QA Engineering ​

  • Visual Regression Analysis and DOM Synchronization Based on Playwright and CDP: Analysis of rendering frame capture and network-idle synchronization techniques using the Chrome DevTools Protocol.
  • Vision-LLM-Based UI Element Bounding Box Inference and Self-Healing Algorithms: A regression test recovery pipeline that leverages visual screen context and coordinates to adapt to CSS class name changes.

2. Distributed Agents & Protocols ​

  • Model Context Protocol (MCP) JSON-RPC Specification Analysis and Tool Orchestration: Analysis of the Claude/Playwright standard tool interface and enterprise security gateway design patterns.
  • Asynchronous Messaging Performance Analysis Based on Java 25 Virtual Threads and AgentScope: Benchmarks on overcoming blocking I/O and handling tens of thousands of concurrent agent communications in Spring Boot environments.

3. AI Models & Knowledge Pipelines ​

  • Enterprise RAG Architecture: Sparse + Dense Hybrid Search and Cross-Encoder Reranking: A pipeline combining BM25 and embedding vectors to improve domain-specific retrieval precision.
  • Practical Fine-Tuning of the Llama-3.2-Vision Multimodal Model: Dataset construction and LoRA tuning for Korean web UI screen component recognition.
  • Root Causes and Mitigation Strategies for Post-Fine-Tuning LLM Performance Degradation: Research on preventing Catastrophic Forgetting and calibrating alignment data.
  • Building a RAG-Based Knowledge Retrieval Pipeline: Unstructured data chunking and metadata filtering strategies.

Research Methodology and Validation Criteria ​

The Empasy engineering team adheres to the following principles across all technical research:

  1. Code-Level Empirical Validation: Rather than stopping at theoretical models, we build executable prototypes or benchmark code to verify performance.
  2. Quantitative Evidence: Technology adoption decisions are driven by quantified metrics including latency, memory footprint, throughput, and failure rate.
  3. Production Resilience Review: Defensive logic is evaluated against edge cases such as network disconnections, thread exhaustion, and delayed DOM rendering.
