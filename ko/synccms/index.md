# SyncCMS: 엔터프라이즈 AI 하이브리드 헤드리스 CMS

> **비개발자 · 도입 검토 안내**: 쉬운 제품 소개는 [SyncCMS 제품 홈페이지(empasy.io)](https://empasy.io/ko/solutions/sync-cms.html){target="_blank" rel="noopener"}에서, 설치 없는 화면 체험은 [통합 데모 포털](https://demo.empasy.io/products/sync-cms/#demo){target="_blank" rel="noopener"}에서 이용하실 수 있으며, 소개서·제안서 PDF는 [제안서 자료실](/proposals/)에서 내려받으실 수 있습니다.

**SyncCMS**(`https://empasy.io/ko/solutions/sync-cms.html`)는 대고객 웹 포털, 모바일 앱 등 기업의 모든 디지털 접점에서 **Nuxt 3 SSR 고속 렌더링, Copywriter-SEO-Publisher 멀티에이전트 스웜(`CmsSwarmWorkflowService`), HTML Head 메타 정보의 동적 중앙 관리 및 차세대 AI 검색(AEO/GEO) 최적화를 제공하는 엔터프라이즈 하이브리드 헤드리스 CMS**입니다.

외산 SaaS의 폐쇄성과 데이터 유출 위험, 국산 레거시 CMS의 노후화된 아키텍처를 극복하고, **Java Spring Boot 4.0 및 AgentScope Java(`io.agentscope:agentscope-harness`) 표준 프레임워크 소스코드를 전면 공개하여 구축된 시스템 전체가 고객사의 독립적인 디지털 소프트웨어 자산으로 내재화**됩니다.

    D --> D1["주요 소스 전면 공개 / 추가 라이선스료 0원 / 안정적 M/M 기술지원"]

### 1. Nuxt 3 SSR & HTML Head 메타 동적 거버넌스
- **하드코딩 완전 탈피**: 개발 배포 없이 백오피스에서 각 페이지별 Title, Description, OpenGraph(OG) 태그, Canonical URL을 마케터가 직접 설정하고 Nuxt 3 SSR 웹 서버(`cms.empasy.io`)와 실시간 동기화합니다.
- **다채널 SNS 메타 프리뷰**: 카카오톡, 페이스북, X(트위터) 공유 썸네일 및 카피를 실시간 시뮬레이션합니다.
- **Lottie & 멀티 포맷 미디어 스트리밍**: Lottie 애니메이션 JSON, WebP, 멀티미디어 자산을 REST API(`/api/v1/cms/...`)로 안정적으로 서빙합니다.

### 2. Copywriter-SEO-Publisher 멀티에이전트 스웜 & AEO·GEO·SEO 검색 최적화
- **3단계 에이전트 스웜(`CmsSwarmWorkflowService`)**: Copywriter(초안 작성) -> SEO/Reviewer(키워드·가독성·메타태그 검수) -> Publisher(발행 및 캐시 무효화) 스웜이 협업하여 고품질 콘텐츠를 자율 생산합니다.
- **Schema.org JSON-LD 자동 생성**: 검색엔진(SEO) 및 AI 답변엔진(AEO)이 즉시 이해할 수 있는 구조화 데이터 스크립트를 CMS가 헤더에 자동 렌더링합니다.
- **생성형 AI(GEO) 인용 표준**: 제목-요약-H1~H3 계층-명확한 출처/작성자/검증일자 포맷을 제공하여 ChatGPT, Perplexity 등 AI 답변 인용을 극대화합니다.

### 3. Java Spring Boot 4.0 프레임워크 & 라이선스 0원
- **자바 표준 프레임워크 전면 공개**: 비즈니스 Controller 소스 및 PostgreSQL 18.6 DDL 전체를 투명하게 제공하여 사내 개발팀의 자유로운 확장을 보장합니다.
- **추가 솔루션 라이선스 비용 0원**: SI 구축비에 솔루션이 포함되어 트래픽/유저수 증가에 따른 추가 과금이 없습니다.
- **안정적인 전문 기술지원 (M/M)**: AI 모델 업데이트 및 검색 알고리즘 변화에 지속 대응하는 체계적인 유지보수 파트너십을 제공합니다.
