# PostgreSQL 17 로컬 컨테이너 데이터베이스 설정

SyncBoot를 포함한 SyncSeries 전 제품군은 Zero-Mock 원칙에 따라 인메모리 더미 DB(H2 등)를 사용하지 않으며, 로컬 개발 환경에서도 **`docker-compose-local.yml` 기반의 실제 PostgreSQL 17 (`pgvector/pgvector:pg17`) 컨테이너**를 표준 데이터베이스로 사용합니다.

---

## 1. 로컬 인프라 컨테이너 기동 (`docker-compose-local.yml`)

```bash
# 로컬 개발용 인프라(PostgreSQL 17, Redis 7, MinIO, RabbitMQ) 단독 기동
docker compose -f docker-compose-local.yml up -d
```

기동 시 `<SubProject>/db/` 하위의 6단계 표준 SQL 스크립트(`00_extensions.sql` ~ `05_sample_dev.sql`)가 자동으로 초기화됩니다.

---

## 2. `pom.xml` 의존성 확인

```xml
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

---

## 3. `application-local.yml` 설정 예시

```yaml
spring:
  datasource:
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://localhost:45432/syncboot_db
    username: ${DB_USERNAME:postgres}
    password: ${DB_PASSWORD:postgres}
```

---

## 4. 데이터베이스 접속 확인

- **Host / Port**: `localhost:45432` (또는 서브프로젝트 단독 실행 시 `localhost:5432`)
- **JDBC URL**: `jdbc:postgresql://localhost:45432/syncboot_db`
- **필수 확장**: `vector`, `uuid-ossp`, `pg_trgm` (`00_extensions.sql`을 통해 자동 활성화)
