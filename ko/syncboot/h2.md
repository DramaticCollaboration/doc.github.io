# PostgreSQL 18.6 로컬 컨테이너 데이터베이스 설정

SyncBoot를 포함한 SyncSeries 전 제품군은 Zero-Mock 원칙에 따라 인메모리 더미 데이터베이스(H2 등)를 사용하지 않으며, 로컬 개발 및 통합 테스트 환경에서도 **`docker-compose-local.yml` 기반의 실제 PostgreSQL 18.6 (`pgvector/pgvector:pg18`) 컨테이너**와 **6-File DB SSOT(`db/00_extensions.sql` ~ `05_sample_dev.sql`)** 체계를 표준 데이터베이스로 사용합니다.

---

## 1. 로컬 인프라 컨테이너 기동 (`docker-compose-local.yml`)

IDE 디버깅 및 로컬 개발을 위한 인프라는 `docker-compose-local.yml`로 단독 기동합니다.

```yaml
services:
  postgres:
    image: pgvector/pgvector:pg18
    container_name: syncboot-postgres-local
    ports:
      - "45432:5432"
    environment:
      POSTGRES_DB: syncboot_db
      POSTGRES_USER: ${DB_USERNAME:-postgres}
      POSTGRES_PASSWORD: ${DB_PASSWORD:-postgres}
    volumes:
      - ./db/00_extensions.sql:/docker-entrypoint-initdb.d/00_extensions.sql:ro
      - ./db/01_schema_system.sql:/docker-entrypoint-initdb.d/01_schema_system.sql:ro
      - ./db/02_schema_domain.sql:/docker-entrypoint-initdb.d/02_schema_domain.sql:ro
      - ./db/03_seed_system.sql:/docker-entrypoint-initdb.d/03_seed_system.sql:ro
      - ./db/04_seed_domain.sql:/docker-entrypoint-initdb.d/04_seed_domain.sql:ro
      - ./db/05_sample_dev.sql:/docker-entrypoint-initdb.d/05_sample_dev.sql:ro
```

```bash
# 로컬 개발용 인프라(PostgreSQL 18.6, Redis 7, MinIO, RabbitMQ) 단독 기동
docker compose -f docker-compose-local.yml up -d
```

## 2. 6-File DB SSOT 표준 구조 (`<SubProject>/db/`)

컨테이너 최초 기동 시 `<SubProject>/db/` 하위의 6단계 표준 SQL 스크립트가 순서대로 실행되어 최신 스키마와 시드 데이터를 구성합니다.

| 실행 순서 | 파일명 | 주요 역할 및 수록 대상 |
| :---: | :--- | :--- |
| **00** | `db/00_extensions.sql` | PostgreSQL 18.6 필수 확장 선언 (`vector`, `uuid-ossp`, `pg_trgm`) |
| **01** | `db/01_schema_system.sql` | 플랫폼 공통 시스템 테이블 DDL (`sys_user`, `sys_role`, `sys_permission`, `sys_dict`, `sys_config` 등) |
| **02** | `db/02_schema_domain.sql` | 도메인 전용 비즈니스 테이블 DDL, HNSW 벡터 인덱스 및 제약조건 (`snake_case` 표준) |
| **03** | `db/03_seed_system.sql` | 초기 최고관리자 계정, 기본 역할(`role_admin`), 공통 사전 코드 및 시스템 기초 메뉴 `INSERT INTO` |
| **04** | `db/04_seed_domain.sql` | 도메인 업무 메뉴(`sys_permission`), 역할 권한 매핑(`sys_role_permission`), 기준 마스터 데이터 `INSERT INTO` |
| **05** | `db/05_sample_dev.sql` | 로컬 개발 및 시연 전용 샘플 픽스처 데이터 (상용 운영 환경 실행 제외) |

## 3. `pom.xml` 의존성 및 `application-local.yml` 설정

### 3.1 Maven 의존성 (`pom.xml`)

```xml
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

### 3.2 로컬 프로파일 설정 (`application-local.yml`)

```yaml
spring:
  datasource:
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://localhost:45432/syncboot_db
    username: ${DB_USERNAME:postgres}
    password: ${DB_PASSWORD:postgres}
```

---

## 4. 데이터베이스 접속 및 상태 검증

- **Host / Port**: `localhost:45432` (또는 단일 포트 매핑 시 `localhost:5432`)
- **JDBC URL**: `jdbc:postgresql://localhost:45432/syncboot_db`
- **필수 확장 확인**:
  ```sql
  SELECT extname, extversion FROM pg_extension WHERE extname IN ('vector', 'uuid-ossp', 'pg_trgm');
  ```
