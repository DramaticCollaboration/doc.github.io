SyncWatch DBスキーマおよび標準REST/MCP API仕様 ​

SyncWatchは、全社6-File DB SSOTデータベース標準（sync-watch/db/00_extensions.sql ~ 05_sample_dev.sql）、PostgreSQL 18.6 (pgvector/pgvector:pg18)、および/api/v1/watch/*単一URLマッピング原則に準拠し、8大グローバル脅威フィード（OSV.dev、GitHub GHSA、NVD CVE、CISA KEV、Nuclei、OWASP CRS、MITRE ATT&CK、KISA）の収集からデュアルルールコンパイル・配信までの全ライフサイクルを永続化します。

1. エンティティ関連図（ER図）および6大ドメインテーブル（watch_*） ​

1.1 ドメインテーブル詳細仕様（sync-watch/db/02_schema_domain.sql） ​

通番テーブル名役割および主要カラム
1watch_feed_source8大グローバル脅威フィード出典マスター
• PK: uuid / UK: provider_code (OSV_DEV_FEED, GITHUB_GHSA, NVD_CVE_FEED, CISA_KEV_CATALOG, NUCLEI_TEMPLATES, OWASP_CRS_FEED, MITRE_ATTACK_STIX, KISA_BOHO_NOTICE)
• 主要カラム: provider_name, site_url, feed_url, feed_format (REST_JSON, YAML_NUCLEI, CRS_CONF, STIX_TAXII, RSS_XML), source_channel, auth_type, sync_interval_min, auto_compile_rule, auto_broadcast, enabled, last_sync_time, last_sync_status, last_sync_count, total_ingested_count
2watch_security_advisory正規化されたセキュリティイシュー台帳
• PK: advisory_id
• 主要カラム: source_channel, feed_provider, external_id（CVE/GHSA/KISA番号）, cwe_id, mitre_code, title, severity (CRITICAL, HIGH, MEDIUM, LOW), cvss_score, exploit_status, affected_ecosystem, affected_packages, vulnerable_version_range, patched_version, summary_text, raw_payload_json (jsonb), matched_asset_count, matched_repo_count, compile_status
3watch_verse_audit_ruleSyncVerse供給用セキュリティ点検ルール（VerseAuditPack）
• PK: rule_id / FK: advisory_id
• 主要カラム: external_id, rule_title, severity, check_channel (SCA_DEPENDENCY, SAST_CODE, DAST_PENTEST), ecosystem, package_name, vulnerable_version_range, patched_version, sast_pattern_regex, dast_probe_method, dast_probe_path, dast_probe_payload, remediation_guide_md, target_agent_code, verified, dispatch_status
4watch_apim_defense_ruleSyncAPIM供給用攻撃パターンルール（ApimDefensePack）
• PK: rule_id / FK: advisory_id
• 主要カラム: external_id, rule_name, attack_category (SQLI, XSS, SSRF, RCE, PATH_TRAVERSAL), mitre_tactic, severity, target_locations (HEADER,URI,QUERY,BODY), target_method, target_path, detection_regex, defense_expression, grammar_fingerprint, positive_samples_json, negative_samples_json, sandbox_verified, tp_rate, fp_rate, dispatch_status
5watch_dispatch_history全社配信および適用フィードバック台帳
• PK: dispatch_id / FK: advisory_id
• 主要カラム: target_system (SYNC_VERSE, SYNC_APIM), rule_id, target_endpoint_url, dispatch_mode (PUSH_BROADCAST, PULL_SYNC), dispatch_status, response_summary, dispatched_by, dispatched_time, feedback_time
6watch_collection_job_log収集バッチおよび診断ドキュメントアップロード実行ログ
• PK: job_id
• 主要カラム: provider_code, job_type (FEED_SYNC, DOC_UPLOAD, RULE_COMPILE), fetched_count, new_advisory_count, compiled_verse_rules, compiled_apim_rules, duration_ms, status, log_detail, executed_time

1.2 PostgreSQL 18.6 コアDDL例 ​

sql
-- sync-watch/db/02_schema_domain.sql
CREATE TABLE watch_apim_defense_rule (
    rule_id VARCHAR(64) PRIMARY KEY,
    advisory_id VARCHAR(64) NOT NULL REFERENCES watch_security_advisory(advisory_id),
    external_id VARCHAR(64) NOT NULL,
    rule_name VARCHAR(255) NOT NULL,
    attack_category VARCHAR(32) NOT NULL,
    mitre_tactic VARCHAR(32) NOT NULL DEFAULT 'T1190',
    severity VARCHAR(16) NOT NULL,
    target_locations VARCHAR(64) NOT NULL DEFAULT 'URI,QUERY,BODY',
    target_method VARCHAR(16) NOT NULL DEFAULT 'ANY',
    target_path VARCHAR(255) NOT NULL DEFAULT '/api/v1/*',
    detection_regex TEXT NOT NULL,
    defense_expression TEXT NOT NULL,
    grammar_fingerprint VARCHAR(128) NOT NULL,
    positive_samples_json JSONB NOT NULL,
    negative_samples_json JSONB NOT NULL,
    sandbox_verified BOOLEAN NOT NULL DEFAULT FALSE,
    tp_rate NUMERIC(5,2) NOT NULL DEFAULT 0.00,
    fp_rate NUMERIC(5,2) NOT NULL DEFAULT 0.00,
    dispatch_status VARCHAR(24) NOT NULL DEFAULT 'DRAFT',
    created_time TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_watch_apim_rule_category ON watch_apim_defense_rule (attack_category, severity);
CREATE INDEX idx_watch_apim_rule_fingerprint ON watch_apim_defense_rule USING gin (grammar_fingerprint gin_trgm_ops);

3. MCP（Model Context Protocol）公開ツール仕様（/api/v1/watch/mcp） ​

SyncWatchは、他のエージェント（SyncVerse、SyncAPIM、SyncInsight）がA2Aプロトコルで脅威インテリジェンスを即座に照会したり、ルールのコンパイル・配信をトリガーしたりできるよう、標準MCPツールを公開しています。

MCPツール名主要パラメーター機能説明
watch_sync_security_feedsproviderCode（任意）8大グローバル脅威フィード（OSV.dev、GitHub GHSA、NVD CVE、CISA KEV、Nuclei、OWASP CRS、MITRE ATT&CK、KISA）の同期および正規化の実行
watch_compile_dual_rulesadvisoryId単一のセキュリティイシューからSyncVerse点検ルール（VerseAuditPack）およびSyncAPIM攻撃パターン（ApimDefensePack）を同時にコンパイルし、サンドボックス検証を実行
watch_dispatch_to_verse_and_apimadvisoryId, targetSystem検証済みのセキュリティ点検ルールおよびWAF仮想パッチルールをSyncVerseとSyncAPIMへ即座にブロードキャスト配信
watch_match_enterprise_sbomecosystem（任意）全社マイクロサービスSBOMパッケージと脆弱性台帳をクロス照合し、影響を受ける資産・リポジトリを算出
delegate_intentintent, instructionA2A自然言語セキュリティインテリジェンスの収集・コンパイル・全社配信の委任実行
