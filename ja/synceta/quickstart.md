# SyncETA クイックスタートガイド

SyncETA は 2 つの方法で開始できます。ローカルおよびステージング環境で素早くテストを体験したい場合は **[方法 1: デスクトップアプリの簡単インストール]** を、チーム単位の集中管理および CI/CD 連携サーバーを構築したい場合は **[方法 2: Docker ベースのオンプレミス構築]** を選択してください。

---

## 方法 1: デスクトップアプリの簡単インストール（推奨 - 1分で開始）

デスクトップアプリは、別途サーバー構築やデータベース設定を行うことなく、OS ごとのインストーラーを実行するだけで即座に起動します。

### ステップ 1: インストーラーのダウンロード
[株式会社エムパシー公式ダウンロードページ（empasy.io）](https://empasy.io/ja/download_eta.html)から、お使いの OS に合った最新の安定版ビルド（v0.0.44）をダウンロードします。

- **Windows**: `SyncETA Setup 0.0.44.exe`（x64 および arm64 対応）
- **macOS**: `SyncETA-0.0.44-arm64.dmg`（Apple Silicon M シリーズ）または `SyncETA-0.0.44.dmg`（Intel）

### ステップ 2: アプリケーションの起動
インストール完了後、デスクトップまたはアプリケーション一覧から **SyncETA** を起動します。別途ログインや外部ネットワーク認証を行うことなく、ローカルモードで即座に起動します。

---

## 方法 2: Docker Compose ベースのオンプレミス構築（エンタープライズ）

社内インフラに SyncETA 中央サーバーおよび Playwright 分散実行ノードをデプロイする方法です。

```bash
# リポジトリのクローンおよびディレクトリの移動
git clone https://github.com/DramaticCollaboration/SyncSeries.git
cd SyncSeries/sync-eta

# コンテナサービスの一括起動
docker compose -f docker-compose.dev.yml up -d
```

サービス起動後、ブラウザで `http://localhost:9000` にアクセスして Web コンソールを開きます。

---

## 最初のテストシナリオ録画および実行ハンズオン

デスクトップアプリまたは Web コンソールの起動後、以下の 4 ステップの手順に従って最初の回帰テストを作成・実行します。

### ステップ 1: プロジェクト作成およびベース URL の登録
1. 左側ナビゲーションで **「プロジェクト」** をクリックします。
2. 右上の **「新規プロジェクト」** ボタンを押し、プロジェクト名（例: `コマースメインフロー`）と開始 URL（例: `https://shop.example.com` または `http://localhost:3000`）を入力します。

### ステップ 2: ユーザーインタラクションの録画
1. 左側メニューから **「シナリオ」** -> **「新しいシナリオ」** を選択します。
2. 対象ブラウザ（Chromium）およびビューポート（1920x1080）を指定したうえで **「録画開始」** をクリックします。
3. 開かれたブラウザウィンドウでユーザー操作を実行します。
   - 検索バーをクリックして検索キーワードを入力
   - 検索実行ボタンをクリック
   - 検索結果一覧から特定の項目をクリック
4. 録画制御ウィンドウで **「録画終了」** を押すと、シナリオが JSON/YAML フォーマットに自動正規化されて保存されます。

### ステップ 3: 検証条件（Assertion）の登録
1. 保存されたシナリオエディターで検証対象となる最後のステップを選択します。
2. **「検証条件の追加」 -> 「要素表示検証」** を選択し、画面内の対象コンポーネント（例: 「詳細情報」領域または「決済ボタン」）を指定します。

### ステップ 4: Playwright エンジン無人実行および自己修復の検証
1. 右上の **「シナリオ実行」** をクリックします。
2. 実行モード（ヘッドレスまたは通常ブラウザ）を選択したうえで **「実行」** を押します。
3. 実行完了後、ダッシュボードでステップ別の成否、所要時間、キャプチャされたスクリーンショット、および自己修復（Self-Healing）の適用履歴を確認します。
