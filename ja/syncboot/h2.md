# PostgreSQL 18.6 ローカルコンテナデータベース設定

SyncBoot を含む SyncSeries 全製品群は Zero-Mock 原則に基づき、インメモリダミーデータベース（H2 など）を使用せず、ローカル開発および結合テスト環境においても **`docker-compose-local.yml` ベースの実際の PostgreSQL 18.6（`pgvector/pgvector:pg18`）コンテナ**と **6-File DB SSOT（`db/00_extensions.sql` ～ `05_sample_dev.sql`）** 体系を標準データベースとして使用します。

---

## 1. ローカルインフラコンテナの起動 (`docker-compose-local.yml`)

IDE デバッグおよびローカル開発用のインフラは、`docker-compose-local.yml` で単独起動します。

```yaml
services:
  postgres:
    image: pgvector/pgvector:pg18
    container_name: syncboot-postgres-local
    ports:
      - "45432:5432"
    environment:
      POSTGRES_DB: syncboot_db
      POSTGRES_USER: ${DB_USERNAME:-postgres}
      POSTGRES_PASSWORD: ${DB_PASSWORD:-postgres}
    volumes:
      - ./db/00_extensions.sql:/docker-entrypoint-initdb.d/00_extensions.sql:ro
      - ./db/01_schema_system.sql:/docker-entrypoint-initdb.d/01_schema_system.sql:ro
      - ./db/02_schema_domain.sql:/docker-entrypoint-initdb.d/02_schema_domain.sql:ro
      - ./db/03_seed_system.sql:/docker-entrypoint-initdb.d/03_seed_system.sql:ro
      - ./db/04_seed_domain.sql:/docker-entrypoint-initdb.d/04_seed_domain.sql:ro
      - ./db/05_sample_dev.sql:/docker-entrypoint-initdb.d/05_sample_dev.sql:ro
```

```bash
# ローカル開発用インフラ（PostgreSQL 18.6、Redis 7、MinIO、RabbitMQ）の単独起動
docker compose -f docker-compose-local.yml up -d
```

## 2. 6-File DB SSOT 標準構造 (`<SubProject>/db/`)

コンテナの初回起動時に `<SubProject>/db/` 配下の 6 段階標準 SQL スクリプトが順番に実行され、最新のスキーマとシードデータが構成されます。

| 実行順序 | ファイル名 | 主な役割および収録対象 |
| :---: | :--- | :--- |
| **00** | `db/00_extensions.sql` | PostgreSQL 18.6 必須拡張の宣言（`vector`、`uuid-ossp`、`pg_trgm`） |
| **01** | `db/01_schema_system.sql` | プラットフォーム共通システムテーブル DDL（`sys_user`、`sys_role`、`sys_permission`、`sys_dict`、`sys_config` など） |
| **02** | `db/02_schema_domain.sql` | ドメイン専用ビジネステーブル DDL、HNSW ベクトルインデックスおよび制約条件（`snake_case` 標準） |
| **03** | `db/03_seed_system.sql` | 初期スーパー管理者アカウント、基本ロール（`role_admin`）、共通辞書コードおよびシステム基礎メニュー `INSERT INTO` |
| **04** | `db/04_seed_domain.sql` | ドメイン業務メニュー（`sys_permission`）、ロール権限マッピング（`sys_role_permission`）、基準マスターデータ `INSERT INTO` |
| **05** | `db/05_sample_dev.sql` | ローカル開発およびデモ専用のサンプルフィクスチャデータ（本番運用環境での実行除外） |

## 3. `pom.xml` 依存関係および `application-local.yml` 設定

### 3.1 Maven 依存関係 (`pom.xml`)

```xml
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

### 3.2 ローカルプロファイル設定 (`application-local.yml`)

```yaml
spring:
  datasource:
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://localhost:45432/syncboot_db
    username: ${DB_USERNAME:postgres}
    password: ${DB_PASSWORD:postgres}
```

---

## 4. データベース接続および状態検証

- **Host / Port**: `localhost:45432`（または単一ポートマッピング時は `localhost:5432`）
- **JDBC URL**: `jdbc:postgresql://localhost:45432/syncboot_db`
- **必須拡張の確認**:
  ```sql
  SELECT extname, extversion FROM pg_extension WHERE extname IN ('vector', 'uuid-ossp', 'pg_trgm');
  ```
